# Tools and alternatives

**Read this first.** These scores are judgements, dated 2026-11-23, made from vendor pages fetched that day and from the adapter work in this repo. They are not benchmarks. A tool marked "not run" was scored from its documentation only. Method: six criteria (fit 35, setup effort 15, reliability and upkeep 15, cost 15, data control 10, integration depth in our adapter 10), each scored 0 to 100 with one evidence line, a weighted total, and closeness (the alternative's fit score divided by the reference tool's fit score). Prices change, so cost is described in plain terms, and a figure appears only where it was read on the vendor page that day, with the link.

The tables below are generated from `data/tool_scores.json` by `python3 tools/score_tools.py`, which also checks the weights and ranges. A unit test fails if the two disagree.

**How to read closeness.** It asks one thing: does the alternative do this part of the job as well as the reference tool. It does not mean the alternative is better in general.

**Voice quality is not scored.** Nobody who built this can hear a voice. Pick the voice by listening to a real test call. See `VOICE-OPTIONS.md`.
